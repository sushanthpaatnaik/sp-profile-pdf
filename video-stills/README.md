# Video stills — Ignitron D product film

Frames pulled from `Grafillium_Ignitron_D_Product_Film` (Google Veo, 1920x1080,
24fps, 10s). Selected by scoring all sampled frames for sharpness, then keeping
only ones visually distinct from each other.

| File | Content | Timecode |
|---|---|---|
| `ignitron-d-bottle-in-hand-01..03.jpg` | Bottle, label legible | ~2.3-3.3s |
| `ignitron-d1-fleet-truck-01..02.jpg` | Fleet truck on highway | ~8.7-8.8s |
| `ignitron-d-endcard-brand-lockup.jpg` | End card with URL | ~9.8s |

All 1920x1080 => **162 x 91 mm at 300dpi**. Enough for a card or half-width
placement; not enough for a full-bleed page.

## Before using these in the catalogue

1. **The Google AI-generated-content watermark is present** in every frame
   (around x 1785-1862, y 928-1004) and will print. It has not been removed.
2. **Each frame carries the film's own burnt-in captions**, which clash with the
   catalogue's typography. The end-card frame is a full lockup.
3. These are excluded from the deployed site via `.assetsignore` — they are
   reference material, not published assets.

Real photography of the physical bottle would beat these on resolution,
provenance and layout freedom, and would also let page 12's product image be
replaced (it is currently a soft crop from the reference PDF).
